# Ad Client Manager

Внутреннее мини-приложение на **PHP 8.3+ / MySQL 8** для рекламных клиентов, расчётных периодов, работ, оплат, PDF, личных задач, истории и аналитики.

## Статус разработки

- Рабочая ветка: `feature/integrated-client-workflow`.
- [Draft PR #2](https://github.com/manufact-test/ad-client-manager/pull/2) — **не сливать до полной приёмки**.
- `main` — исходная протестированная основа; `deploy` — релизная ветка Hostinger; feature-изменения пока **не размещены** в Hostinger.
- Оценка готовности всей системы: **≈78%** на 21.10.2026. Она НЕ готова для реальных клиентских данных.

## Разработанные возможности в feature-ветке

Единые реальный/демо клиенты, поиск/архив/повторный старт; месячные периоды и работы; частичные оплаты, корректировки, возвраты; частные PDF с заменой и передачей; напоминания, личные задачи; аналитика реальных клиентов по валютам и категориям; канонический CSV-импорт истории; безопасный CSV-экспорт реальных финансов и выписка конкретного клиента; два уровня прав и аудит.

Исходники: `app/core.php`, `app/workflow.php`, `app/finance.php`, `app/export.php`, `app/import.php`, `app/documents.php`, `app/reminders.php`, `app/audit.php`, `index.php`.

## Тестирование

GitHub Actions выполняют проверки PHP, MySQL 8, HTTP, прав доступа, PDF, CSV импорта/экспорта и восстановление SQL+PDF в полностью изолированной среде. Все тестовые данные вымышленные. Для локальных быстрых проверок — `php tests/smoke.php`, `php tests/document_smoke.php`, `php tests/auth_regression.php`. Для интеграционных тестов нужна **только отдельная** MySQL-база и `TEST_DB_HOST`, `TEST_DB_NAME`, `TEST_DB_USER`, `TEST_DB_PASSWORD`.

**Важнейшее условие:** репозиторий пока **PUBLIC**, поэтому запрещены любые настоящие документы, персональные данные, пароли или реальные финансы в GitHub и тестах. После завершения и приёмки пользователь переводит GitHub в **PRIVATE**, повторно проверяются CI/CD и безопасность. **Только потом** можно вводить настоящих клиентов. Не менять чужие сайты, базы и Cron Jobs Hostinger.
