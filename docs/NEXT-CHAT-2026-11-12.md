## Что исправлено

В карточке клиента, в блоке **«Документы и оплаты»**, ранее отправленный **акт или иной PDF без суммы** оставался целиком раскрытым среди ожидающих действий. Причина: интерфейс относил к закрытым только записи с `received_at IS NOT NULL`, а у документа без платежа нет получения денег.

Теперь:
1. Если `entry_kind=document`, `amount IS NULL`, `sent_at IS NOT NULL`, `received_at IS NULL`, запись попадает в закрытый по умолчанию `<details class="ledger-paid ledger-sent">`, подпись **«Отправленные документы · N»**.
2. Отдельная историческая группа **«Оплаченные · N»** сохранена как была; финансовые документы, по которым ждут оплаты, остаются раскрытыми, равно как и неотправленные акты.
3. Внутри раскрываемой группы остаются скачивание, отмена отправки, директорские изменение и удаление. Отмена отправки перемещает акт обратно в активные документы; повторная отправка снова скрывает.
4. При отсутствии активных документов не показываем ложную заглушку «Нет ожидающих...» поверх закрытых групп. Группировка одинакова для директора и сотрудника с учётом существующего ограничения видимости документов по дате.

**Не меняли:** PHP-действия, деньги, статусы платежей, клиентские данные, вложенные PDF, права, БД и миграции. Уже отправленные акты без суммы автоматически свернутся при следующем открытии карточки. Тесты проверяют реальный HTTP-цикл загрузка→отправка→сворачивание→отмена→повторная отправка и независимость неоплаченного счёта.
