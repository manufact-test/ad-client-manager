## Чего эта проверка НЕ гарантирует

Это эвристический поиск по **доступным diff patches** и текстовым файлам. Он не охватывает полностью потерянные/переписанные ветки, форки, закрытые/истекшие workflow artifacts, внешние кэши, GitHub лог, ссылки на внешние выгрузки и значения секретов с нестандартными шаблонами. Он не доказывает отсутствия всех персональных данных: имена/финансовые суммы сами по себе неотличимы от вымышленных по регулярному выражению. Нельзя утверждать, будто весь публичный след очищен.

2. Если обнаружен секрет — **отозвать/перевыпустить его**; изменение PUBLIC на PRIVATE не отменяет прежнее раскрытие.
