5. Подключить копию приложения к **тестовой** БД через тестовый приватный конфиг и проверить вход директора/сотрудника, карточку клиента, скачивание PDF, аналитику, архив, работу прав.

## Совместимость новой защиты от повторной оплаты

Сценарий `tests/restore_fixture.php` и шаг `Verify backup/restore of SQL and private PDFs in a second database` в `.github/workflows/ci-deploy.yml`. Используются только придуманные данные, отдельные MySQL `adclients_test` → `adclients_restore_test`, одноразовые PDF и автоматическая очистка.

**Оставшийся блокер релиза:** повторить аналогичную проверку реальной инфраструктуры **без раскрытия настоящих данных**, с отдельной тестовой БД/директорией после завершения основного функционала. До этого восстановление на Hostinger считается непроверенным.
